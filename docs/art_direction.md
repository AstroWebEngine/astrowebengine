# AWE art direction

Worlds with a maker’s mark. Observatory precision, industrial civilization.

AWE supplies coherent tools and a recognizable maker’s mark. The creator supplies the character, judgment and care that make a game worth playing. AI assistance is a tool, not a quality guarantee.

## Palette

| Role | Color |
|---|---|
| Charcoal background | #161310 |
| Panel | #211c17 |
| Raised panel | #30271e |
| Ivory text | #f4ecdc |
| Muted ivory | #bcaf9e |
| Amber action | #ecaa68 |
| Copper secondary | #c47b4b |
| Rule | #4c3c2e |

Use amber for actions and selected states; copper for decorative rules and secondary accents. Semantic status colors must remain distinguishable and readable. Blue may identify a specific category, but is not the brand’s dominant color.

## Typography and shape

Use the system sans-serif stack for prose and headings, and system monospace for coordinates, quantities and instrument labels. Strong hierarchy, restrained tracking, thin rules, and 2–3px corners. Avoid decorative text that compromises legibility. Orbital geometry is an accent, never a layer over essential information.

## Shared assets

`static/brand/awe-mark.svg`: orbital maker’s mark, ivory star with amber orbit and copper trajectory. `awe-favicon.svg`: favicon. `awe-wordmark.svg`: horizontal name and tagline. SVG wordmark text uses system fonts; convert text to outlines before print production.

The mark identifies the engine; it is not a certification of a game’s quality. Keep a visible Made with AWE attribution on default presentations. Game artwork and palettes may vary. Preserve explicit player skins.

## Imagery

Show functioning civilizations: infrastructure, strong ship silhouettes, purposeful machinery and legible star charts. Light should have a physical source. Assets should explain what a unit or structure does. Avoid interchangeable glow, gratuitous nebula backgrounds and decorative control clutter.

## Review

Check desktop and narrow mobile layouts, keyboard focus, reduced motion, contrast, and saved skin precedence. Inspect the website, login, setup, lobby, gallery, game and admin together. Publish only after review.
